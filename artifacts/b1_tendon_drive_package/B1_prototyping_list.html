五、推荐打样流程

  1. Layout 工程化 — Altium Designer / KiCad 真实 PCB Layout (4层/2oz/阻抗控制)
  2. SI/PI/EMC 仿真 — 信号完整性、电源完整性、EMC 仿真
  3. 设计评审 — 对照清单检查车规级 CAN 收发器等特殊器件
  4. 投板打样 — 嘉立创/华秋 (4层 ~50元/5片, 2oz铜厚)
  5. 钢网 — QFN48 (U_GATE) 必须开刻钢网
  6. SMT 贴片 — TO-220-7P (MOSFET) 手工焊, 其他回流焊
  7. FCT/ICT 测试 — 100% ICT 飞针 + FCT 功能测试 (固件自动从 foc-firmware 生成)
  8. 实机装配 — 腱伺服电机 ×4 + 拮抗 VSA 电机 ×4 + 8ch 张力传感器
  9. HIL 联调 — 接入 HIL 半实物仿真, 验证 FOC 电流环 / PWM / 编码器反馈

六、认证要求

  • 功能安全: ISO 13482 个人护理机器人, SIL 2
  • 安全功能: STO (Safe Torque Off) < 1μs 硬件独立比较器
  • 爬电/电气间隙: 3.0mm (30V+)
  • 腱驱动安全: 握持失效 → 断电锁止 (drop_protection = true)
