## 2. 感知系统架构

```
传感器输入:
  ├── 视觉: 头部摄像头 + 胸部摄像头 (RGB-D, 20Hz)
  ├── 触觉: GelSight × 3指 (100Hz, 高维时空张量)
  ├── 本体感觉: 关节编码器 + 电流传感器 + IMU
  └── 力/力矩: 腕部六维力传感器

融合策略 (混合融合):
  Early Fusion ──→ 原始信号拼接 → 单一网络
  Late Fusion  ──→ 各模态独立编码 → 决策层融合
  Hybrid Fusion ──→ 分层交互 + 注意力机制 ← [选择]

概率基础:
  · 多速率 EKF: 视觉(20Hz,可能丢帧) + 触觉(100Hz)
  · μ 在线估计: RLS 递推最小二乘
  · 机会约束: f_n ≥ ‖f_t‖/(μ̂ − z·σ_μ)
```

## 3. 接触动力学核心方程

### 3.1 浮基动力学 (机器人本体)

$$M(q)\dot\nu + C(q,\nu)\nu + g(q) = S^T\tau + \sum_{i=1}^{n_c} J^{c_i}(q)^T\lambda_i$$

其中 $q\in\mathbb{R}^{n_q}$ 关节位形含 6 维浮基，$\nu$ 基座速度，$\lambda_i$ 接触力。

### 3.2 接触力学统一

- **Hertz接触**: $k = \frac{4}{3}E^*\sqrt{R^*}$
- **Hunt-Crossley**: $f = k\delta^n(1 + b\dot\delta)$ （$n=1.5$）
- **Stribeck摩擦**: $\mu(v) = \mu_c + (\mu_s - \mu_c)\exp(-\|v\|/v_s)$
- **二阶锥摩擦锥**: $\|\mathbf{f}_t\|_2 \leq \mu \cdot f_n$

### 3.3 力闭合条件

$$\text{rank}(G) = 6, \quad w_i > 0, \quad n_{contact} \geq 4$$

### 3.4 脉冲动力学 (Dyno)

$$M(\nu^+ - \nu^-) = J^{c^T}\Lambda, \quad \|\Lambda_t\| \leq \mu\Lambda_n$$

## 7. 关键约束与边界

```
1. 电机自动关机响应 < 1μs (硬件级, 不可软件实现)
2. 内核实时调度 jitter < 100μs (PREEMPT_RT + isolcpus)
3. RL 训练需 1000x 仿真迭代 + 100x 真实微调
4. GelSight 输出 921KB/帧 → 需要 GPU 预处理
5. 触觉传感器成本是视觉 50-500x → 数据稀缺
6. 端到端 VLA 推理延迟必须 < 50ms (20Hz 控制)
7. GelSight 软指尖 Hertz 载荷极限 ~60N@5mm → 需骨架并联方案
8. μ 不确定性: 无裕度点估计滑脱率 50% → 需机会约束
```
