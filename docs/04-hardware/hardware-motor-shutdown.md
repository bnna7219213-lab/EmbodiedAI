# 硬件设计专题: 自动关机电机驱动的完整硬件设计

> 本文档回答核心问题: "如何从硬件角度设计一个具有自动关机电机驱动的具身智能体？"
>
> 关键词: PCB、MOSFET、比较器、硬件锁存、FOC、电流采样、安全保护

---

## 1. 系统视角: 自动关机在机器人安全中的位置

```
具身智能体安全层级:

L0 机械安全: 柔性外壳 / 碰撞检测皮肤 / 关节力矩上限
L1 硬件安全: ★ 自动关机 (本文重点) ★
L2 固件安全: 软件看门狗 / 通信心跳 / 异常检测
L3 模型安全: 动作幅度限制 / 碰撞预测 (AI 模型内嵌)
L4 系统安全: 多级急停按钮 / 远程关机 / 紧急策略

自动关机是 L1 — 最后一道也是最可靠的一道防线。
即使软件崩溃、模型出错、通信中断, 硬件仍然可以 < 1ms 内切断电机。
```

---

## 2. 自动关机的三种模式

| 模式 | 触发条件 | 延迟 | 恢复方式 |
|---|---|---|---|
| **A. 自动停机 + 自动恢复** | 短时过流 (< 5ms) | < 1μs | 自动重试 |
| **B. 自动停机 + 需确认** | 持续过流 / 过温 | < 1μs | MCU 清零锁存 |
| **C. 完全断电 + 手动恢复** | 短路 / 灾难性故障 | < 1μs | 物理按钮 / 上电复位 |

设计原则: 大多数情况用模式 A (避免误触发影响任务), 严重情况用模式 B/C (确保安全)。

## 3. 功率电路设计

### 3.1 三相全桥拓扑 (核心)

```
                V_MOTOR (48V)
                    │
        ┌───────────┼───────────┐
        │           │           │
   ┌────┴────┐ ┌────┴────┐ ┌────┴────┐
   │  Q1 (高) │ │  Q3 (高) │ │  Q5 (高) │  ← 高侧 MOSFET
   │ NVMHS    │ │ NVMHS    │ │ NVMHS    │     (N 沟道增强型)
   └────┬────┘ └────┬────┘ └────┬────┘
        │           │           │
        ├─ Phase U ─┼─ Phase V ─┼─ Phase W ─┐
        │           │           │            │
   ┌────┴────┐ ┌────┴────┐ ┌────┴────┐       │
   │  Q2 (低) │ │  Q4 (低) │ │  Q6 (低) │       │  ← 低侧 MOSFET
   │ NVMHS    │ │ NVMHS    │ │ NVMHS    │       │
   └────┬────┘ └────┬────┘ └────┬────┘       │
        │           │           │            │
        └───────────┼───────────┘            │
                    │                        │
             R_shunt_U (1mΩ)                 │
             R_shunt_V (1mΩ)  ← 电流采样     │
             R_shunt_W (1mΩ)                 │
                    │                        │
               ═════╧════════════════════════╝ GND

器件选型:
  MOSFET: BSC016N06NS (Infineon)
    Vds = 60V, Rds(on) = 1.6mΩ, Qg = 55nC
    理由: 极低导通电阻 + 适合 48V 系统 + 栅电荷适中

  电流采样电阻: 1mΩ 合金电阻 (四端子/开尔文连接)
    功率: 30A² × 1mΩ = 0.9W → 选 3W 电阻留余量
    精度: ±0.5%, 低温漂
```

### 3.2 栅极驱动器

```
栅极驱动器: DRV8301 (TI)

能力: 三相半桥栅极驱动
  - 高侧: 自举供电, 1.0A 拉电流 / 2.0A 灌电流
  - 低侧: 1.0A 拉电流 / 2.0A 灌电流
  - 内置 Buck 转换器 (给 MCU 或传感器供电)
  - 3 个电流检测放大器 (增益可编程 10/20/40/80 V/V)
  - SPI 接口: 配置 + 故障读取

连接方式:
  MCU (STM32G4) ─ SPI ──→ DRV8301 (配置/故障)
  MCU (STM32G4) ─ 6×PWM ─→ DRV8301 (INHx/INLx)
  DRV8301 (GHx/GLx) ──→ MOSFET 栅极
  
  关键: DRV8301 的 nFAULT 引脚 →(低电平有效)→ MCU GPIO + 自动关机锁存
```

## 4. 自动关机电路详解

### 4.1 过流保护 (最关键)

```
                    VREF_OC (来自 DAC 或电阻分压)
                              │
                         R1   │   R2
                    ┌─── 10kΩ ├─ 10kΩ ──┐
                    │         │          │
                    │    ┌────┴────┐     │
                    │    │ +       │     │
                    ├────┤  TLV3201 ├────┤
                    │    │ -       │     │
                    │    └────┬────┘     │
                    │         │          │
                  V_sense     │         (输出)
               (来自 INA240)   │          │
                              │     ┌────┴────┐
                              │     │ SR锁存   │
                              │     │ 74HC279 │
                              │     │         │──→ nGATE_DISABLE
                              │     │ SET     │   (低有效, 到 DRV8301)
                              │     │         │
                              │     │ RESET ←── MCU GPIO (软件清零)
                              │     └────┬────┘
                              │          │
                         ═════╧══════════╧═══ GND

工作过程:
  正常: V_sense < VREF_OC, 比较器输出低, 锁存器 RESET, MOSFET 导通
  过流: V_sense > VREF_OC (如 30A × 1mΩ × 20 = 0.6V)
       比较器 40ns 翻转 → 锁存器 SET → nGATE_DISABLE 拉低
       → DRV8301 全部 MOSFET 关断 (~200ns)
       → 总响应时间 < 1μs

  恢复: MCU 确认故障清除后, GPIO 拉低锁存器 RESET → 重新使能
```

### 4.2 过温保护 (慢速保护)

```
  NTC 热敏电阻 (B 值 3950K, 10kΩ @ 25°C)
       │
  VCC ─┤── NTC ──┬── GND
                 │
                R_pullup (10kΩ)
                 │
                 ──── V_NTC (到 ADC 和比较器)

  温度-电阻对照:
    25°C  → 10kΩ  → V = 2.5V (中点)
    85°C  → 1.5kΩ → V = 0.7V (阈值)
    100°C → 0.9kΩ → V = 0.45V (极端)

  比较器阈值 V_ref = 0.7V (对应 ~85°C)
  当 V_NTC < 0.7V (温度 > 85°C) → 关断

  与过流保护不同:
    - 过温不需要快, 热时间常数秒级, 用比较器 + RC 延时 (10ms) 即可
    - MCU ADC 也可以读 ADC 值做软件降额 (75°C 开始降功率)
```

### 4.3 通信看门狗

```
  MCU (主控, 上位机)
    │
    ├── 每 10ms 发送 CAN 帧: heartbeat = 0xA5
    │
    ▼
  MCU (关节, 关节驱动板)
    │ (正常: 每 10ms 收到心跳)
    │
    ├─── 555 单稳态触发器 (或 TPS3808)
    │    RC 时间常数 = 50ms
    │    每收到心跳 → 定时器复位
    │    超过 50ms 无心跳 → 输出低 → 触发关断
    
    ▼
  (超时) → 锁存器 SET → 关断电机
           → 需手动/CAN 复位

  意义: 上位机死机 / 通信断线 / 主控重启 → 关节自动停机, 防止乱动
```

### 4.4 硬件看门狗集成

```
全关机信号整合:

  过流 ──┐
  过温 ──┤
  通信丢失 ──┼──→ OR 门 (74HC32) ──→ SR 锁存器 ──→ nFAULT_GATE
  紧急按钮 ──┘                                    (低有效, 关断所有 MOSFET)
  MCU 故障 ──┘

  74HC32 四路二输入或门 (用其中一路或多路):
    任意一路高 → 输出高 → 锁存器 SET
    
  SR 锁存器 (74HC279):
    SET 来自任一故障源
    RESET 来自 MCU 的主动清除

  复位后: 所有 MOSFET 关断, 电机三相浮空 (惯性滑行停止)
  真正的急停 (非滑行) 需要短路三相 (能耗制动), 需要额外继电器
```

## 5. 电流采样详细设计

### 5.1 采样方式对比

| 方式 | 精度 | 延迟 | 适用 | 备注 |
|---|---|---|---|---|
| 低侧采样 (shunt) | 高 | 快 | PWM 期间 | 需要 PWM 同步 |
| 相电流霍尔传感器 | 中 | 中 | 连续信号 | 温度漂移 |
| MOSFET Rds(on) 采样 | 低 | 最快 | 低成本方案 | 精度差 |

**选择: 低侧采样 + 高增益电流检测放大器**

### 5.2 低侧采样 + INA240

```
  低侧 MOSFET (Q4/Q6) ────┐
                           │
                      R_shunt (1mΩ)
                           │
                      INA240 (电流检测放大)
                           │
                          GND

  INA240:
    零漂移, 双向, 共模范围 -4V ~ 80V
    增益: 20 V/V (可选 50/100)
    带宽: 400 kHz (适合 20kHz PWM)
    
  输出: V_out = I × R_shunt × Gain
    20A × 1mΩ × 20 = 0.4V
    30A × 1mΩ × 20 = 0.6V  ← 过流阈值对应
  
  PWM 同步采样:
    ADC 应在 PWM 低侧开通期间采样 ( MOSFET 导通时才有电流 )
    在 PWM 关断期间采样结果 = 0 (或噪声)
    
    STM32G4 方式:
      定时器 PWM 模式触发 ADC (硬件同步)
      → 自动在 PWM 开通中点采样
      → 无需软件干预

### 5.3 FOC 电流环控制流程

```
  (ADC 采样) 三相电流 I_a, I_b, I_c
       │
       ▼
  克拉克变换 (Clark): I_α, I_β
       │
       ▼
  帕克变换 (Park): I_d, I_q  (旋转坐标系)
       │
       ▼
  PI 电流环:
    I_d → PI → V_d (目标 I_d = 0, 最大转矩电流比)
    I_q → PI → V_q (目标来自速度环/力矩指令)
       │
       ▼
  反 Park 变换: V_α, V_β
       │
       ▼
  SVPWM 调制: 三路占空比 D_a, D_b, D_c
       │
       ▼
  定时器 PWM 输出 → 栅极驱动 → MOSFET → 电机

  环频率: 10kHz (100μs 周期)
  每次 ADC 中断执行上述全部运算
```

## 6. PCB 布局的五大黄金法则 (功率板)

### 6.1 电流路径最小化

```
错误布局:                    正确布局:
MCU ──→ 预驱动 ──→ 长走线 → MOSFET    MCU ──→ 预驱动 ──→ MOSFET ──→ 电机
       (20mm+)   (感性EMI)                (<10mm)       (<5mm)

关键:
  栅极驱动走线: 尽量短, 尽量直, 远离开关节点
  功率走线: 铺铜或宽走线 (>50mil @ 20A)
  采样走线: 从 R_shunt 引脚直接到放大器 (<5mm), 差分走线
```

### 6.2 地平面的完整性

```
   ┌──── 完整地平面 (不可切割) ────┐
   │                                │
   │   ┌───┐                        │
   │   │IC │  ← 数字信号地          │
   │   └─┬─┘                        │
   │     │ 单点连接                   │
   │     ├─────────────             │
   │   ┌─┴─┐   ← 功率地 (低侧)      │
   │   │PG │                        │
   │   └───┘                        │
   │                                │
   └────────────────────────────────┘

   功率地回流:
     R_shunt → MOSFET 源极 → 功率铺铜 → 电源负极
     这条路径尽量短, 不经过数字地平面
```

### 6.3 热设计

```
   MOSFET 散热:
     ┌─────── MOSFET TO-263 ──────┐
     │                             │
     │   ┌───────────┐             │
     │   │  MOSFET   │             │
     │   │   外壳    │ ← 散热焊盘    │
     │   └─────┬─────┘             │
     │   ┌─────┴─────┐             │
     │   │   PCB     │             │
     │   │  大面积   │             │
     │   │  铺铜     │ ← 热过孔阵列  │
     │   └─────┬─────┘             │
     │         │                   │
     │   ┌─────┴─────┐             │
     │   │  铝散热壳  │ ← 导热垫    │
     │   │           │    (厚 1mm)  │
     │   └───────────┘             │
     └─────────────────────────────┘
     
   热过孔: 0.3mm 孔, 间距 1mm, 阵列覆盖 MOSFET 焊盘下方
   铝壳: 关节外壳复用, 导热垫填充间隙
```

### 6.4 隔离与抗干扰

```
  数字信号 (MCU, SPI, PWM) │ 模拟信号 (电流采样, 比较器)
         │                         │
    数字地平面              模拟地平面 (通过电阻单点连接)
         │                         │
         └──── 光耦 / 数字隔离器 ──┘
         
  功率功率:
    PWM 信号跨越隔离屏障 → 用隔离栅极驱动 (如 Si8271)
    或 DRV8301 内置电容隔离
```

### 6.5 可测试性 (DFT)

```
  测试点放置:
    - TP1: V_MOTOR (电源电压)
    - TP2: V_GATE (栅极驱动波形)
    - TP3: V_SHUNT (电流采样波形)
    - TP4: nFAULT (故障信号)
    - TP5: 3.3V 参考电压
    - TP6: 晶振输出

  测试点要求:
    - 1mm 圆形焊盘, 无阻焊
    - 间距 > 2.54mm (可插探针)
    - 板边 5mm 以内 (方便夹子)
```

## 7. 自动关机 PCB 四层堆叠规范

```
┌────────────────────────────────────────────────┐
│ L1: Top (功率层)                                │
│    MOSFET (Q1~Q6)                              │

├────────────────────────────────────────────────┤
│ L3: Signal + Power (信号/电源层)                │
│    栅极驱动信号走线                             │
│    SPI / UART / CAN 通信走线                   │
│    电源线 (48V, 12V, 5V, 3.3V)                 │
├────────────────────────────────────────────────┤
│ L4: Bottom (控制层)                            │
│    MCU (STM32G474)                             │
│    比较器 (TLV3201)                            │
│    SR 锁存器 (74HC279)                         │
│    看门狗 (TPS3808)                            │
│    自动关机逻辑电路 (全部集中在此层)            │
│    LDO / DCDC                                  │
│    调试连接器 (SWD + UART)                     │
└────────────────────────────────────────────────┘

板材: FR-4 Tg170 (耐热)
铜厚: L1/L4-1oz, L2/L3-2oz (功率层)
层压: 标准 FR-4 层压, 介电常数 4.5 @ 1GHz
最小孔径: 0.3mm (激光钻孔 for 埋头孔)
最小间距: 4mil (100μm) — 常规工艺
表面处理: ENIG (镍金) — 平整, 适合细间距
```

## 9. 测试验证方案

### 9.1 自动关机响应时间测试

```
测试仪器: 示波器 (100MHz+), 电流探头 (AC/DC 30A+)

测试步骤:
  1. 电机空载运行, 电流 ~5A
  2. 突然堵转 (机械制动或人为卡住) → 电流飙升
  3. 示波器触发: MOSFET Vgs 下降沿
  
  测量参数:
    t1: 电流开始上升时刻
    t2: MOSFET Vgs 下降到 50% 时刻
    t_response = t2 - t1

  合格标准: t_response < 1μs (硬件保护)

波形分析:

  电流 I  ▲
         │        ╭─── (上升到 > 30A)
  5A  ──┤       ╱
         │      ╱
         │     ╰╮
         │      ╰─────── (关断后衰减)
         └──────────────→ 时间
         t1    t2
         |←<1μs→|

  Vgs   ▲
         │ ╲
  10V ──┤  ╲
         │   ╲
         │    ╲___________
         └──────────────→ 时间
              t2
```

### 9.2 自动关机阈值精度测试

```
测试步骤:
  1. DAC 输出不同 V_ref (模拟不同阈值: 10A/20A/30A/40A)
  2. 用电子负载灌电流, 缓慢增加
  3. 记录实际关断电流

合格标准: 实测阈值与设定值误差 < ±5%

阈值设定示例:
  R_shunt = 1mΩ, Gain = 20
  I_limit = 10A → V_ref = 0.2V
  I_limit = 20A → V_ref = 0.4V
  I_limit = 30A → V_ref = 0.6V (出厂默认)
  I_limit = 50A → V_ref = 1.0V (峰值, 允许瞬时)
```

## 10. 与具身智能体整体的关系

自动关机电机驱动是具身智能体硬件层的一个模块,
但它是整个安全体系的关键。

```
                    具身智能体
                        │
            ┌───────────┼───────────┐
            │           │           │
        AI 决策层      感知层      执行层
       (VLM/VLM)    (视觉/力)    (电机+驱动器)
                                    │
                              ┌─────┴─────┐
                              │ 自动关机    │
                              │ PCB 模块    │
                              └─────┬─────┘
                                    │
                            ┌───────┼───────┐
                         过流   过温   通信中断
                         <1μs  <10ms   <50ms
```

自动关机不是独立存在的:

1. 与 PCB 的关系: 自动关机电路直接在 PCB 上实现, 布局影响响应速度
2. 与 MCU 的关系: 自动关机可以被 MCU 禁用 (调试模式)
3. 与 AI 模型的关系: 自动关机的状态是 AI 模型的输入之一 ("当前关节异常")
4. 与结构的关系: MOSFET 通过导热垫连接到外壳, 外壳是为散热服务的结构件
5. 与安全认证的关系: 认证必须验证自动关机功能 < 1ms 响应

## 附录 A: EdaLab 能力匹配评估

EdaLab 当前可直接用于关节驱动 PCB 的模块:

| EdaLab 模块 | 可复用程度 | 说明 |
|---|---|---|
| SPICE 网表生成 | 中 | 可用于功率电路仿真 |
| ERC 规则 | 低 | 面向原理图检查, 功率电路规则不同 |
| PCB 自动布局 | 低 | 教学级, 功率板需手工布局 |
| Verilog 仿真 | 无 | 数字域, 不直接适用 |
| GDSII 导出 | 无 | 芯片级, 不直接适用 |

EdaLab 需要扩展的能力:

| 需求 | 优先级 |
|---|---|
| 大电流 PCB 布线规则 | P0 |
| 功率器件热仿真 | P1 |
| 电流检测放大器建模 | P0 |
| 比较器 SPICE 行为模型 | P0 |
| 半桥功率级仿真 | P1 |
| MOSFET 驱动时序分析 | P0 |
