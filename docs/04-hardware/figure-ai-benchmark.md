## 3. 核心技术拆解

### 3.1 Helix 2.5 模型分析 (2026.09.17 发布)

- 30 个陌生家庭实测 (未提前采集数据)

## 5. 与本计划的对比

### 5.1 可借鉴

| Figure 做法 | 本计划借鉴方式 |
|---|---|
| AI × 硬件联合优化 | 每个 Phase 同步推进模型和硬件 |
| 零样本泛化为目标 | 仿真 + 域随机化 + 行为克隆 |
| Index 数据集 | 构建自己的数据采集管线 |
| 端到端 VLA (Phase 3) | 先在仿真验证,再迁移真实 |
| 20Hz 控制频率 | 目标一致 (硬件需匹配) |
| 自动安全机制 | 电机驱动强制硬件级保护 |

### 5.2 不可复制但可规避

| Figure 优势 | 本计划的规避路径 |
|---|---|
| $2B+ 资本 | 轮臂方案降本 5-10x |
| 200+ 团队 | 先做精简版,由小到大 |
| Index 数据集 (数万小时) | 仿真数据 + 公开数据集 |
| 三代机器人迭代 | 直接设计较完整的首代 |

### 5.3 差异化赛道选择

Figure / Tesla 瞄准通用双足人形。本计划选择 **轮臂复合** 作为第一阶段:
- 放弃双足行走 (价值最低但难度最高)
- 用省下的资源和复杂度换取:
  - 更高负载 (不耗能在平衡)
  - 更长续航 (轮式能耗低)
  - 更低成本 (驱动器少 20+)
  - 更快落地 (80% 家庭任务可由轮式完成)

## 6. Figure AI 对行业的启示

1. **具身智能的瓶颈不在 AI, 在数据和硬件 — 其次在 AI**
   Helix 2.5 的 56% 零样本成功率看起来不够高, 但这是在"从未见过的家庭"中。
   证明算法方向正确, 但需要 10x 数据才能到 90%。

2. **端到端路线已被验证可行**
   Figure 是端到端路线的最强证据。分治方案(视觉+规划+控制)已被证明不如端到端流畅。
   
3. **AI 与硬件的深度耦合是护城河**
   Figure 不做通用 AI 公司, 也不做通用机器人公司。
   它做的是"AI-model-designed-for-hardware, hardware-designed-for-AI"。
   这种特异性是最难被复制的。

4. **2026 年是"家庭实测元年"**
   Figure 进入 30 个陌生家庭, 标志着具身智能从实验室走向真实场景。
   其他玩家需要在 2-3 年内达到类似水平, 否则将被拉开差距。

## 7. 关键问题

### 7.1 Helix 的 56% 成功率意味着什么?

如果一个机器人在全新家庭中:
- 56% 的概率能完成"整理客厅"类任务
- 44% 的概率会失败 (掉落物品 / 碰撞 / 错误操作)

对于 demo 和教学: 足够。
对于产品化: 不够 (需要 > 95%)。

**路径**: Figure 需要 10x 数据 + 更精细的力控制 + 更好的,long-horizon 规划。

### 7.2 我们能否在 2 年内接近 Helix 2.5 的水平?

分情况讨论:

| 方面 | 概率接近 | 说明 |
|---|---|---|
| 训练框架 | 高 (80%) | 已有 LLMInnovation 基础 |
| 仿真数据管线 | 中 (50%) | Isaac Sim 生态成熟 |
| 真实数据采集 | 低 (20%) | 硬件迭代周期长 |
| 硬件力控 | 低 (15%) | 需要多代关节迭代 |
| 端到端训练 | 中 (40%) | 需要大量试错 |
| **综合接近度** | **极低** | 资金 + 团队不是量级 |

**结论**: 本计划 Phase 1-2 的目标不是复制 Figure, 而是在特定小众场景 (如工业桌面操作) 中达到可演示水平。长期对标 Figure 需要 5+ 年持续投入。
