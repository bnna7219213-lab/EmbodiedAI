## 〇、为什么"十层不够"的数学本质

前一份文档把系统切成十层。这个"切"是一种**观测选择**——你在选择哪些自由度作为"显层"，哪些被"吸收"进子结构内。

数学上，一层要能独立存在，需要满足两个条件：

**条件一：时间尺度分离（Time-scale separation）。** 若子系统的快变模态（特征值 λ_f）与慢变模态（λ_s）满足：

```
|Re(λ_f)| ≥ 10 × |Re(λ_s)|
```

则快的那个可以"准静态化"（singular perturbation），慢的可以直接驱动快的而忽略快模态的动力学——**形成一层**。

**条件二：能量/信息吞吐的有界性。** 每一层作为"信号变换器"，必须满足：

```
E_out ≤ η × E_in      （能量层, η < 1）
I_out ≤ C             （信息层, C 为信道容量）
```

两个条件缺一不可。

**反例**：电机驱动层 L2 (10kHz) 和安全保护层 S (0.8μs) 之间的时间常数比超过 10000×——看似可分离。但是！S 层的硬件比较器直接切断 PWM，产生 **10A/μs 的 di/dt**，激发电缆的分布电感谐振（~MHz 级）。这个 MHz 模态既不在 L2 的模型里（它用状态平均法把开关抹掉了），也不在 S 的模型里（它的传递函数只到几百 kHz）。

**所以十层不够的数学本质是**：每一层在做"平均化/准静态化"时都会扔掉一些模态，这些被扔掉的模态在跨层处可能重新被激发——它们不归属于任何一层，但它们确实在系统里。真正完备的模型需要 **层内+耦合项** 的联合表述。

这份文档就用数学把这个讲清楚。

## 二、芯片内部的物理：从 Maxwell 到器件方程

### 2.1 Maxwell 方程组（电磁场基础）

芯片外部（PCB 走线、驱动板母线、电机气隙）的物理过程受 Maxwell 方程组约束：

```
∇ · D = ρ_f        (Gauss 定律: 电场的散度由自由电荷决定)
∇ · B = 0         (Gauss 磁定律: 磁单极子不存在)
∇ × E = -∂B/∂t   (Faraday 电磁感应: 变化的磁场产生电场)
∇ × H = J_f + ∂D/∂t  (Ampère-Maxwell: 电流 + 位移电流产生磁场)
```

其中：
- **D = εE**（电位移场，ε 是介电常数；描述电容、绝缘特性）
- **B = μH**（磁感应强度，μ 是磁导率；描述电感、变压器、电机气隙磁场）
- **J_f = σE**（欧姆定律的微观形式，σ 电导率；描述导通损耗）

这四个方程看似与"造机器人"很远，实际上定义了所有被认为理所当然的事件的边界条件：

**PCB 走线的信号完整性问题**：当信号上升沿 tr < 1ns 时，走线长度 > tr × c / √ε_r / 2 ≈ 10cm 就必须当作传输线处理（不再适用 KCL/KVL 集总参数近似）。这是因为 ∂D/∂t（位移电流项）不再可忽略——电磁波在走线上的传播延迟与上升沿同阶。

**电机气隙磁场**：永磁体产生 B_h，载流绕组产生 B_i，二者叠加得到气隙合成 B_g。力密度 f = J × B（Lorentz 力定律）沿气隙表面积分得到电磁转矩。dq 变换的数学本质是把三相静止坐标系下的 B_i 旋转到与转子磁场同步的坐标系——在同步坐标系下，交流量变成直流量，这才是 FOC 能做到"像控制直流电机一样控制交流电机"的数学原因。

### 2.2 半导体物理基础（Poisson + 连续性方程）

芯片内部的信息处理依赖于 PN 结的非线性 I-V 特性，由以下耦合 PDE 组描述：

```
∇²φ = -ρ/ε_s                          (Poisson 方程)
∂n/∂t = (1/q)∇·J_n + G_n - R_n        (电子连续性方程)
∂p/∂t = -(1/q)∇·J_p + G_p - R_p       (空穴连续性方程)

其中漂移-扩散电流：
J_n = q μ_n n E + q D_n ∇n            (电子漂移+扩散)
J_p = q μ_p p E - q D_p ∇p            (空穴漂移+扩散)
```

其中 φ 为静电势，n、p 为电子/空穴浓度，μ 为迁移率，D 为扩散系数（满足 Einstein 关系 D/μ = kT/q），G、R 为产生-复合率。

**工程推论**：

- **MOSFET 导通电阻 Rdson**：物理上 = 沟道电阻 + JFET 区电阻 + 漂移区电阻 + 衬底电阻。温度升高 → 晶格振动增强 → μ_n 下降 → Rdson 增大 → 损耗进一步增大 → 温度再升高。这是**热奔溃（thermal runaway）** 的数学根源：正反馈 + 散热不及时 → 不可逆损坏。
  
- **IGBT 的关断拖尾电流**：导通时漂移区充满少数载流子（电导调制），关断时这些载流子需要复合。复合时间 τ ∝ τ_lifetime（少数载流子寿命，可通过掺金/铂或电子辐照调节）。拖尾电流产生关断损耗 E_off = ∫ v_CE(t) · i_C(t) dt。**IGBT 不适合高频**的本质就是这个拖尾的高频谐波频谱。

- **SiC MOSFET 的兴起原因**：SiC 的临界击穿电场 E_c ≈ 2.2 MV/cm（Si 约 0.3 MV/cm），在相同耐压下漂移区厚度可减到 1/10，电阻下降 2~3 个数量级。同时 SiC 热导率 4.9 W/(cm·K)（Si 1.5），散热能力更强。数学上这对应 Poisson 方程中击穿电压 BV ∝ ε_s × E_c² / (2 × N_d) 的物理限制被打出了一个新参数空间。

### 2.3 状态空间平均法（功率电子的核心数学）

功率电子变换器（Buck、Boost、逆变器）的核心分析工具是**状态空间平均法（State-Space Averaging, Middlebrook & Cuk, 1976）**：

一个周期 T_s 内，开关有 k 个拓扑状态，每个状态持续 d_i × T_s（∑d_i = 1）：

```
ẋ(t) = A_i x(t) + B_i u(t),  t ∈ [(i-1)·d_i·T_s, i·d_i·T_s)
```

对一周期平均（假设 x 变化远慢于开关频率，即 **f_sw >> 系统带宽**）：

```
ẋ_avg = (∑ d_i A_i) x_avg + (∑ d_i B_i) u
     = A_d x_avg + B_d u
```

其中 d_i 为占空比（对于 Buck：d = V_out/V_in）。

**这个公式做了什么重大的近似？** 它把开关纹波（频率 = f_sw）这一高频模态完全消除在模型之外。在 L2 FOC 的带宽（几 kHz）内这个近似没问题；但对 EMC 分析（MHz 级谐波）和高频谐振（~MHz），这个模型就**数学意义上不存在**了——因为特征模态已经被"平均"掉了。

这是前一份文档说"十层不够"的数学实例之一：**开关频率以上的动力学没有在任何一层被模型化，它们只存在于 Maxwell 方程的全波解里**（需要用 FEM/BEM 方法在三维空间+时间上解 Maxwell，自由度~10⁶ 到 10⁹）。

## 三、执行层的力学：从拉格朗日到接触

### 3.1 欧拉-拉格朗日方程（多体动力学基础）

一个 N 自由度机器人（离散多体）的动力学由拉格朗日方程描述：

```
d/dt (∂L/∂q̇) - ∂L/∂q = τ + J_c^T f_c

其中 L = T - V（拉格朗日量 = 动能 - 势能）
```

展开后得到机器人动力学的标准形式：

```
M(q) q̈ + C(q, q̇) q̇ + g(q) = τ + J_c^T f_c

M(q) ∈ ℝ^{N×N}  —— 质量矩阵（正定、对称、一致正定）
C(q, q̇) ∈ ℝ^{N×N} —— 科氏力/离心力矩阵
g(q) ∈ ℝ^N        —— 重力向量
τ ∈ ℝ^N           —— 驱动力矩（电机 + 传动）
J_c^T f_c ∈ ℝ^N   —— 接触力在关节空间的映射（J_c 为接触雅可比）
```

这个方程有几个关键数学性质：

**性质 1（Skew-symmetry of Ṁ - 2C）**：

```
Ṁ(q, q̇) - 2C(q, q̇)  是斜对称（skew-symmetric）的。
```

这意味着在能量分析中 x^T (Ṁ - 2C) x = 0，它是**无源系统（passive system）**的关键性质，是 L3 阻抗控制全局稳定性的数学基础——Lyapunov 函数可以取 H = ½ q̇^T M(q) q̇，V̇ = q̇^T (τ - g) 不含科氏力项，控制设计因此简化为"能量注入/耗散"。

**性质 2（重力势能的有界性）**：

```
||g(q)|| ≤ g_max,  ∀q ∈ ℝ^N
||M(q)|| ≤ m_max,  ∀q ∈ SE(3)^k
```

这两个有界性保证了 PD 控制器的增益可以固定（不依赖 q），可用一个全局常值增益完成镇定：τ = K_p (q_d - q) - K_d q̇ + g(q) 全局渐近稳定。

### 3.2 接触力与库伦摩擦的互补约束（LCP）

机器人与环境的接触不是简单的力 = K × 位移。它有一组互补约束（complementarity conditions）：

```
0 ≤ f_n ⊥ φ(q) ≥ 0
（接触力 f_n ≥ 0，间隙 φ(q) ≥ 0，且两者至少一个 = 0）

||f_t|| ≤ μ f_n
（库伦摩擦：切向力不超过摩擦系数 μ × 法向力）
```

数学上这是一个**线性互补问题（Linear Complementarity Problem, LCP）**：

```
w = M z + q,  w ≥ 0,  z ≥ 0,  w^T z = 0
```

求解 LCP 的数值方法（Lemke 算法、投影 Gauss-Seidel、NCP 函数光滑化）是接触动力学仿真器的核心。

**意义**：LCP 是**不可微的**（因为互补条件引入了不连续性），意味着：
- 传统梯度优化不能直接处理接触序列规划（MCTS 用的是采样而非梯度）
- 接触发生时系统维数跳变（开 → 闭），这是混合系统（hybrid system）的典型特征
- control-Lyapunov 函数在接触切换面处的可微性需要用 Filippov 解框架处理

### 3.3 Stewart 平台与绳索驱动的几何

特殊的传动结构引入额外的几何约束：

**Stewart 平台**（六自由度运动平台）的逆运动学有解析解，正运动学需要解 40 次多项式：

```
||R·p_i + t - b_i||² = L_i²,  i=1,...,6

其中 R ∈ SO(3) 姿态矩阵, t ∈ ℝ³ 平移向量
      p_i 是上平台铰点（本体坐标系）, b_i 是下平台铰点（惯性坐标系）
      L_i 是作动筒长度
```

40 个解的物理含义：同一个作动筒长度组合可能对应 40 种不同的上下平台相对位姿，其中只有 1 种在物理上可达。**这是机构学奇异性的数学表达**。

### 3.4 柔性结构与振动模态（偏微分方程）

前文假设连杆是刚体。实际关节和连杆是连续的弹性体，其运动方程是**偏微分方程**：

```
ρ A ∂²u(x,t)/∂t² + EI ∂⁴u(x,t)/∂x⁴ = f(x,t)

其中：
  ρ —— 密度，A —— 截面积，EI —— 弯曲刚度
  u(x,t) —— 横向位移（位置 x, 时间 t）
  f(x,t) —— 分布力（电机定子力、电磁力）
```

做分离变量 u(x,t) = Σ φ_i(x) · q_i(t)，得到**模态坐标下的常微分方程组**：

```
m_i q̈_i + c_i q̇_i + k_i q_i = Φ_i^T F(t)    (i = 1, 2, ..., ∞)

其中 φ_i(x) 是第 i 阶模态振型（即 ∂⁴φ/∂x⁴ = (ρA ω_i² / EI) φ 的本征函数解）
      k_i / m_i = ω_i²（第 i 阶固有频率的平方）
```

这个展开的数学含义：

- 理论上系统是无限维的（有无穷多阶模态）
- 工程中只保留前几阶（通常前 6~10 阶），因为高模态阻尼大、能量耦合弱
- 留下的截断误差就是系统"模态截断"引入的**非最小相位零点**——它在高频段引入额外相位滞后，高阶模态是限制控制带宽的终极物理原因
- 这就是前一份文档提到的 60~80mm 关节腔体、刚性-柔性结合板、封闭无风扇驱动板需要结构动力学分析的数学基础：你不能用 ODE 描述，必须回到 PDE；或者用 ODE 近似但因为截断带来未建模动态

### 3.5 摩擦力学：Stribeck 曲线

摩擦不是常数。完整的速度-力关系：

```
F_f(v) = F_c · sgn(v) + (F_s - F_c) exp(-|v/v_s|^δ) · sgn(v) + σ_2 · v

其中：
  F_c —— 库伦摩擦力（与速度大小无关的方向相反的恒力）
  F_s —— 静摩擦力（比 F_c 大，启动时需克服的阈值）
  v_s —— Stribeck 速度（从静摩擦过渡到动摩擦的临界速度, 越小 F_f 随 |v|↑ 下降越多）
  δ —— 形状参数（经验，通常 0.5~2.0）
  σ_2 —— 粘性摩擦系数（高速段的线性项）
```

**为什么 Stribeck 效应对 L3 阻抗控制是灾难**：低速时摩擦随速度增加而**下降**（负阻尼），提供负阻尼能量 → 系统振荡。解决方法是：
- 用 LuGre 模型（连续可微版本）描述，或用 dither 信号（叠加高频小幅振荡把系统"振"在线性区）

## 四、控制与估计：从卡尔曼到模型预测

### 4.1 卡尔曼滤波（最优估计器——高斯线性情形）

卡尔曼滤波是在线性高斯假设下的**方差意义下最优**估计器：

```
模型：x_k = F x_{k-1} + B u_k + w_k,    w_k ~ N(0, Q)
观测：z_k = H x_k + v_k,                  v_k ~ N(0, R)
```

时间更新（预测）：
```
x̂_k|k-1 = F x̂_{k-1|k-1} + B u_k
P_k|k-1 = F P_{k-1|k-1} F^T + Q
```

测量更新：
```
K_k = P_k|k-1 H^T (H P_k|k-1 H^T + R)^{-1}    （卡尔曼增益）
x̂_k|k = x̂_k|k-1 + K_k (z_k - H x̂_k|k-1)     （状态修正）
P_k|k = (I - K_k H) P_k|k-1                    （协方差更新）
```

在项目 `multirate_ekf.py` 中的实现，本质上就是上述递推的扩展（EKF = 对非线性系统做局部线性化：F 被 Jacobian J_f 替代）。

**卡尔曼滤波的深层数学含义**：它是在所有线性无偏估计器中方差最小的那个——可以通过正交投影定理（Hilbert 空间中的投影）严格证明。这也是它在无法被更复杂的粒子滤波替代的中等维度系统中一直是主流的数学原因。

### 4.2 LQR 与 H∞ 控制（最优控制——确定性 vs 鲁棒）

**有限时间 LQR**：
```
min J = x^T(t_f) S x(t_f) + ∫[x^T Q x + u^T R u] dt
s.t. ẋ = Ax + Bu
```

解由 Riccati 方程给出：

```
Ṡ = -A^T S - S A + S B R^{-1} B^T S - Q   (微分方程形式)
K = R^{-1} B^T S                           (最优反馈增益)
```

**无限时间 LQR**：令 Ṡ = 0，得到代数 Riccati方程 (ARE)：

```
A^T S + S A - S B R^{-1} B^T S + Q = 0
```

求解 S（对称半正定解）后得到常值增益 K。这一整套理论依赖**可控性 + 可观测性**这两个代数性质（rank[B, AB, ...] = rank[C; CA; ...] = n）。

**H∞ 控制（最优鲁棒控制）**：

当系统存在未建模动态 Δ(s)（||Δ||∞ < 1/γ），LQR 可能不稳定。H∞ 只关心最坏情况：

```
||T_{wz}||_∞ < γ

其中 T_{wz} 是从扰动 w 到性能输出 z 的闭环传递函数
      H∞范数 ||G||∞ = sup_ω σ̄(G(jω))   （频率响应的最大奇异值）
```

H∞ 控制的数学结构：
- 通过 Riccati 方程的"双形式"（对应两个耦合 Riccati 方程同时可解）
- γ（性能水平）越小，鲁棒性越强
- 联系到结构奇异值 μ 分析 → μ 给出能容忍多大的结构不确定性

前一份文档中"modeled_hil / measured_hil"分级就是在这里产生意义：从 EdaLab 引擎"modeled"参数得到的控制器只能达到数学意义下的"标称性能"，需要真实 HIL 数据才能在数学意义下证明鲁棒稳定性（因为 ||Δ(s)|| 的真实上界只有真机能给出）。

### 4.3 模型预测控制 (MPC)：在线优化

MPC 在每个控制周期求解一个开环最优控制问题：

```
min_{u_0,...,u_{N-1}}  Σ_{k=0}^{N-1} (x_k^T Q x_k + u_k^T R u_k) + x_N^T P x_N
s.t.  x_{k+1} = f(x_k, u_k)
      x_k ∈ X,  u_k ∈ U
      x_0 = x(t)
```

**关键数学性质**：

（1）**递归可行性 (Recursive Feasibility)**：如果初始可行，则每一步都可行。证明用反证法 + 终端约束 set terminal set 是不变集（即若 x_N ∈ X_f，则 x_{N+1} ∈ X_f）。

（2）**渐近稳定性 (Asymptotic Stability)**：把目标函数 J* 作为 Lyapunov 函数，J* 沿闭环轨线递减。

（3）**凸化**：对于线性系统 + 凸约束，MPC = 一个 QP（二次规划），多项式时间可解。对于非线性系统 + 接触，MPC = 一个 NLP（非凸规划），全局最优不可保证，需要在每个周期内用内点法/SQP 快速找到局部可行解。前一份文档 §八.3 中提到的"RL + MPC"混合架构就是让 RL 帮忙搜索一个高效初始猜测，加速 NLP 收敛。

### 4.4 端口哈密顿系统（多域耦合的数学框架）

整个机电系统可以用一个统一的数学框架表述——**端口哈密顿系统（Port-Hamiltonian System, PHS）**：

```
ẋ = [J(x) - R(x)] ∂H/∂x(x) + g(x) u
y = g(x)^T ∂H/∂x(x)

其中：
  H(x) —— 系统总储能（磁能 + 动能 + 弹性能 + 电场能）
  J(x) —— 反对称互连矩阵（描述能量如何在各储能元件间路由）
  R(x) —— 半正定阻尼矩阵（描述耗散）
  u, y —— 输入/输出端口对（因果互反：力/速度、电压/电流）
```

PHS 框架的两个致命优势：

**优势 1：能量是显式的**。系统总储能 H 及以其为核心的 Lyapunov 函数 Ḣ = -∂H^T R ∂H + y^T u。不需要额外构造 Lyapunov 函数——它已经内嵌在哈密顿结构里。这对应前一份文档 §八.一 中"热-电磁-机械三场耦合"的基本理论统一：电能 + 磁能 + 机械能 + 热能 可以全部用储能函数 H 的总和描述。

**优势 2：PHS 的无源性（passivity）保证级联稳定**。两个 PHS 系统若各自无源，则它们的级联仍无源。这意味着：若电机驱动是 PHS、机械臂是 PHS、触觉传感器是 PHS，则三者级联后的整体稳定性有保障——**这是混合系统镇定理论的数学保证**。

这也是为什么前一份文档坚称横切层 S 必须是独立通道——把安全链建模为 PHS 子系统，用无源性证明它不会破坏其他子系统的稳定性。

## 五、机器学习与决策：从信息论到策略优化

### 5.1 信息论基础

离散分布 p 的熵（Shannon entropy）——信息源不确定性：

```
H(p) = - Σ_i p_i log p_i
```

连续分布的微分熵：

```
h(p) = - ∫ p(x) log p(x) dx
```

KL 散度（相对熵）——两个分布之间的距离（非对称！）：

```
D_KL(p || q) = ∫ p(x) log(p(x)/q(x)) dx
              = H(p, q) - H(p)    （交叉熵 - 熵）
```

KL 散度的关键性质：D_KL ≥ 0（Gibbs 不等式），D_KL = 0 当且仅当 p = q 几乎处处。

**在 RL 中的关键作用**：TRPO/PPO 中"策略更新不能太快"的约束正是：

```
E_{s~ρ_π} [ D_KL(π_old(·|s) || π_new(·|s)) ] ≤ δ
```

每次策略更新的 KL 距离被限制在半径 δ 球内。数学上这是在 Fisher 信息度量下的小球约束，Fisher 信息矩阵定义：

```
F(θ) = E_{π_θ} [ ∇_θ log π_θ(a|s) · ∇_θ log π_θ(a|s)^T ]
```

这个矩阵是 KL 散度的二阶 Taylor 展开（KL 的无穷小版本），所以"在 KL 限制下优化"等价于 "在 Fisher 度量下的最速下降"——也就是**自然梯度法（Natural Gradient）**。策略梯度的自然梯度形式即为 **TRPO**。

### 5.2 最大熵 RL（SAC 算法的数学基础）

SAC（Soft Actor-Critic）的目标是在最大化累积回报的同时最大化策略的熵：

```
J(π) = Σ_t E_{π} [ r(s_t, a_t) + α H(π(·|s_t)) ]
```

引入的"温度参数"α 控制熵的权重。对最优策略的数学解有如下闭式：

```
π*(a|s) ∝ exp(Q*(s,a) / α)

即在最优时，策略是指数函数形式——Softmax 动作选择
```

这个结果的伟大之处在于：它把优化问题转化为对 Q 函数的拟合问题，不需要直接在策略参数上做极大似然。**SAC 在本项目中的实现（`rl_algorithms.py` 中的 SAC 类）直接依赖这一数学结构**。

### 5.3 行为克隆的数学原理与误差累积

行为克隆（Behavior Cloning, BC）通过模仿专家的 (s, a) 数据集恢复策略 π_θ：

```
min_θ E_{s~π_E, a~π_E(·|s)} [ ||π_θ(s) - a||² ]
或等价地：max_θ Σ_i log π_θ(a_i | s_i)
```

**误差累积定理**：若 BC 策略在每个状态的期望误差是 ε，则 E[ cumulative loss after T steps ] 随 T 增长：

```
E[ Σ_t ℓ_t ] ≤ T² ε    （对标准 BC，最坏情况是 T²）
E[ Σ_t ℓ_t ] ≤ T ε    （对 DAgger，最坏情况是 T）
```

这个 T² vs T 的区别**定义了为什么纯 BC 在长 horizon 任务上注定失败**——即使每一步只偏差 1%，T=100 的累积误差可以达到 100%。这迫使项目用 RL 完全取代 BC（或至少用 BC 初始化 + RL 微调）。

### 5.4 Vision-Language-Action 模型的数学结构

VLA 模型（对应 `vla_model.py` 中的 `VLATransformerBlock`）是一个因果解码器（Causal Decoder-only Transformer）：

输入：x = [视觉 tokens | 语言 tokens | 本体感受 tokens]
目标：预测下一组动作 tokens

注意力机制的数学表达（single-head）：

```
Attention(Q, K, V) = softmax(Q K^T / √d_k) V

其中 Q = X W_Q  （查询）, K = X W_K, V = X W_V
      d_k = 维度 / head数（这里是 head_dim）
      softmax 把最后一维归一化为概率分布
```

GQA（Grouped Query Attention）变体（本项目采用的 LLaMA-style）：

```
GQA:  假设 n_q 个 query head, n_kv 个 key/value head, n_q > n_kv
      KV head i 共享给 block 内的一组 Q head。
      注意力矩阵的维度从 (n_q, n_q) 降到 (n_q, n_kv/n_q)
      效果：KV cache 内存减少，推理加速，损失可控（≈ 1% 性能下降）
```

VLA 的 action 预测头（对应 `action_tokenizer.py`）：

连续动作回归：
```
â = W_o · h_L    （h_L 是 decoder 最后一层的 hidden state）
```

离散动作分类（tokenization）：
```
p_k = softmax(W_o · h_L)_k
â = Σ_k p_k · b_k    （b_k = bin centers, k = 1,...,K）
```

离散化 + 分类相比直接连续回归的优势：**模态坍缩的避免**——连续回归会把多个可能动作的平均输出（"右手既伸杯又伸墙中间"），所以动作分辨率足够（K 很大时）时分类行为等于连续。

### 5.5 STL 鲁棒度与可导性（形式化安全的数学）

信号时态逻辑（Signal Temporal Logic, STL）的鲁棒度（robustness）ρ 满足以下递归定义：

```
ρ(G[a,b] φ, t) = min_{t'∈[t+a,t+b]} ρ(φ, t')       （全局: 最差情况）
ρ(F[a,b] φ, t) = max_{t'∈[t+a,t+b]} ρ(φ, t')       （最终: 最好情况）
ρ(X[a] φ, t)   = ρ(φ, t+a)                         （下一时刻）
ρ(φ → ψ, t)    = max(-ρ(φ,t), ρ(ψ,t))             （蕴含）
ρ(φ ∧ ψ, t)    = min(ρ(φ,t), ρ(ψ,t))              （合取）
ρ(φ ∨ ψ, t)    = max(ρ(φ,t), ρ(ψ,t))              （析取）
ρ(¬φ, t)       = -ρ(φ,t)                          （否定）
```

关键性质：**鲁棒度是状态的连续可微函数（除非穿过 φ(t) = 0 的切换面）。** 这意味着：

- 在安全区内远离边界时，ρ > 0 且 ∇ρ 存在，可以用梯度下降把系统推回更安全的区域
- 在边界上 ρ = 0，不可微——需要通过次梯度（subgradient）或正则化（如用 sigmoid 近似 sign 函数）处理

STL 鲁棒度作为 MPC 的约束或 RL 的 reward shaping：

```
maximize  E[ Σ γ^t r(s_t, a_t) ] + η · ρ(φ_safe, t)
subject to  MPC dynamics
```

这给出一个**渐进安全**保证：只要初始状态 ρ(φ, 0) > 0，则在 t → ∞ 下几乎必然不违反——这是系统能用在人身边的数学许可。

## 六、仿真与数值方法：算法的数学

### 6.1 接触动力学的 DAE 指标分析

半隐式 Euler 接触模拟的问题结构是：

```
(1) v_{n+1} = v_n + h M^{-1} (f_ext + J^T λ_{n+1})
(2) φ(x_{n+1}) ≥ 0,  λ_{n+1} ≥ 0,  λ_{n+1}^T φ(x_{n+1}) = 0
```

把 (2) 代入 (1) 得到一个在 λ_{n+1} 上的互补问题。如果 φ 的梯度线性无关（横截相交），则该 LCP 有唯一解。

关键参数：**DAE 指标（Differentiation Index）**。指标表示需要几次时间微分才能把 DAE 纯化为 ODE：

- Index-0：已经是 ODE，无约束
- Index-1：需要一个微分方程 + 一个代数约束
- Index-2：需要两次微分才能纯化
- Index-3：需要三次微分

**接触 + 库伦摩擦 = Index-3 DAE**。这是接触仿真器数值困难的数学根源：
- 非光滑点（stick-slip 切换）处高阶导数不存在
- 需要特别的数值方法（事件驱动法: 检测 φ=0 的过零点）
- 前一份文档中 StructuralFEMEngine 能算 10⁻⁶ 但非真正 FEM：真正基于 Index-3 DAE 的接触仿真需要隐式积分 + 更大的 Jacobian 矩阵求逆

### 6.2 常微分方程的稳定性与隐式积分

前向 Euler（显式）：
```
x_{n+1} = x_n + h · f(x_n)
```
稳定区域：在复平面上是以 (-1/h, 0) 为圆心、半径 1/h 的圆——**有限**。
刚性（stiff）系统（特征值实部 << 0）必须用隐式方法：

后向 Euler（隐式）：
```
x_{n+1} = x_n + h · f(x_{n+1})
```

稳定区域：**几乎整个左半平面**（A-稳定）。代价是每一步需要解非线性方程（通常用 Newton-Raphson）：

```
F(x_{n+1}) = x_{n+1} - x_n - h · f(x_{n+1}) = 0

x^{(k+1)}_{n+1} = x^{(k)}_{n+1} - [I - h·J_f(x^{(k)}_{n+1})]^{-1} F(x^{(k)}_{n+1})
```

本项目 mujoco_env 用半隐式（symplectic Euler）：保留后向 Euler 的数值稳定性，但不做完全的 Newton 迭代——在 "非刚性但需要长时间保持能量" 的仿真与"刚性需要大时间步" 之间取折中。

### 6.3 有限元法 (FEM) 的变分基础（为什么当前 EDA-Lab 不是真 FEM）

一个力学系统的平衡方程：

```
∇·σ + f = ρ ü    （运动方程）
```

边界条件：u 在 Γ_u 上给定，σ·n 在 Γ_t 上给定。

Galerkin 方法：找试探函数 u^h = Σ N_i(x) · a_i，使得加权残差正交于测试函数 v：

```
∫_Ω σ(u^h) : ε(v) dV = ∫_Ω f·v dV + ∫_{Γ_t} t·v dA,   ∀ v ∈ H^1_0(Ω)
```

离散化后：K a = f_ext，即**刚度矩阵 × 位移向量 = 外力向量**。

当前项目 EdaLab StructuralFEMEngine 用的是**解析梁公式 + 板公式**，等价于只取一阶形函数、不组装全局刚度矩阵。它能在 O(n) 量级算出量级判断，但在需要局部应力集中（切口/孔边）的情形就失效了。这正是为什么前一份文档说它"量级判断不出错，但不能替代认证级仿真"的数学原因。真正 FEM 需要从三维弹性力学出发的完整四阶刚度张量 C_ijkl 和四阶应变-位移矩阵 B 的组装与 Crout/LU 分解——通常是 O(n^{4/3}) 的运算量，自由度 n ≈ 10⁶ 量级。

### 6.4 域随机化（Domain Randomization）的数学结构

DR 把参数不确定性建模为一个分布 π(θ)，训练策略 π_φ 最大化**最坏情形期望**：

```
max_φ E_{θ~π} [ E_{π_φ} [ Σ γ^t r(s_t, a_t) | θ ] ]
```

在实现中，每个 episode 从 π(θ) 独立采样一次 θ。关键数学含义：

- 若 π 的支集足够宽，则在 θ 真值（测量得到）处策略仍表现良好
- 信息论上，DR = 用采样去近似一个期望，收敛速率 O(1/√N_episodes)
- 与贝叶斯优化的关系：DR 是频率学派方法，贝叶斯优化是贝叶斯方法——后者理论上更优，但实践上维度 > 20 时计算不可行

## 七、通信与信号的数学

### 7.1 传输线方程（电报方程）

前向提到"走线长度 > 10cm 必须当作传输线"的数学依据是电报方程：

```
∂V(x,t)/∂x = -L' · ∂I(x,t)/∂t - R' · I(x,t)
∂I(x,t)/∂x = -C' · ∂V(x,t)/∂t - G' · V(x,t)
```

其中 L', R', C', G' 是单位长度的分布参数。在射频下解这个方程得到：

```
V(x,t) = V⁺ e^{-αx} cos(ωt - βx) + V⁻ e^{+αx} cos(ωt + βx)
```

前向波（入射）和反向波（反射）的叠加。反射系数：

```
Γ = (Z_L - Z_0) / (Z_L + Z_0)
```

当负载阻抗 Z_L 不等于特性阻抗 Z_0 时发生反射——这就是 PCB 走线需要阻抗控制的数学原因。对应前一份文档中"Why SI matters"。

### 7.2 脉宽调制 (PWM) 与谐波

PWM 的输出电压是幅值为 V_dc、占空比为 d 的方波。Fourier 级数展开：

```
v(t) = d · V_dc + (2V_dc/π) Σ_{n=1}^{∞} (sin(nπd)/n) · cos(nωt)
```

**含义**：
- 直流分量 = d × V_dc（期望的平均电压）
- 谐波多到无穷（衰减率 ~1/n）
- 谐波频谱的包络由 sin(nπd)/n 决定：当 nπd = 整数时，该次谐波为零
- **死区效应**（TOF，Turn-Off Delay）：实际 PWM 上下管存在死区时间 t_d，引入低次谐波（尤其是 5 次、7 次），是电机转矩脉动和 EMC 问题的数学来源。

## 八、多物理场耦合的抽象数学

### 8.1 微分-代数方程 (DAE) 的全系统形式

整个具身智能系统在不考虑离散切换时，可以写成 DAE 形式：

```
E(x) ẋ(t) = f(x(t), u(t), θ)      (微分部分: x 包括电/磁/机械状态)
0       = g(x(t))                  (代数部分: 基尔霍夫定律/约束/接触)
y(t)    = h(x(t))                  (输出: 姿态/速度/力)
```

其中：
- E(x) 是**奇异质量矩阵**（非所有状态都有惯性/储能/电容）
- g(x) = 0 是代数约束（可以是非线性的）
- θ 是参数向量（受制造分布影响）

这个 DAE 可以涵盖所有物理层的耦合，但：

- **数值求解的条件**：Jacobian ∂(Eẋ - f)/∂ẋ 在平衡点处非奇异
- **稳定性**：DAE 的特征值分布决定

### 8.2 混合自动机（Hybrid Automaton）

当引入离散切换（接触开/关、档位切换、安全链触发）时，系统升级为**混合自动体**：

```
H = (Q, X, f, Init, Inv, E, G, R)

Q —— 离散模式集合 (自由飞行/接触/滑动/抱死)
X —— 连续状态空间 (关节相空间)
f —— 每个模式内的 ODE 右端函数
Init ⊆ Q × X —— 初始状态集合
Inv: Q → 2^X  —— 每个模式的不变集（什么条件下保持在模式内）
E ⊆ Q × Q     —— 边（哪些模式可以切换到哪些）
G: E → 2^X    —— 切换的守卫条件（切换触发的门限）
R: E × X → 2^X —— 重置映射（切换后状态跳变）
```

混合系统可达集计算的时间复杂度是指数级的 |Q|。这就是为什么前一份文档说"验证难"——理论上能在数学上证明系统绝不在 Q × X 中的 Bad 集合内，但状态空间的维度和离散模数带来的组合爆炸使得可达集计算在当前 X ∈ ℝ⁴⁰ 时计算不可行（需要过度近似，引入假阳性）。

### 8.3 Lyapunov 指数与系统稳定性

判断非线性系统在不动点附近的渐近稳定性，需要求 Jacobian 的**全部特征值**：

```
ẋ = f(x)   在 x* 不动点 (f(x*) = 0)
Jacobian J = ∂f/∂x |_{x=x*}

若 Re(λ_i(J)) < 0  ∀ i  →  渐近稳定
若 Re(λ_i(J)) > 0  ∃ i  →  不稳定
```

对混沌系统（如微小摩擦下的倒立摆），更进一步的特征是 **最大 Lyapunov 指数**：

```
λ_max = lim_{t→∞} (1/t) ln (|δZ(t)| / |δZ(0)|)
```

λ_max > 0 意味着**确定性混沌**——初始条件微小差异指数级放大，长期不可预测。这对项目来说意味着：L6 和 L5 层的行为在理论上只能做概率性安全论证（reachability + chance constraints），不能做确定性保证。这也是把"形式安全"和"概率安全"并行的数学原因。

## 九、从十层到无限维——为什么真正的模型没有"层"

这一节给出"十层不够"的最终数学证明。

### 9.1 函数空间的分解：Sobolev 空间

系统的完整状态 u(t, x) 是**空间坐标** x 和**时间** t 的函数。它属于某个 Sobolev 空间：

```
u ∈ H^s(Ω × [0,T]) = { ∫_Ω Σ_{|α|≤s} |D^α u|² dx < ∞ }
```

其中 α 是多指标（偏导数的阶次组合），s 是范数的光滑性参数。

十层的"切"等价于 Sobolev 空间的有限维投影：u ≈ Σ_{i=0}^9 u_i · ψ_i(x)，用 9 个基函数逼近。前一份文档定义的各层，就是特定的基函数选择。

**所以"十层不够" 等价于：**

当 u 的真实正则性 s 很高（系统有很多尖锐的瞬态、冲击、折射波）时，9 个基函数不足以让误差

```
||u - Σ u_i ψ_i||_{H^s} < ε_tolerable
```

小于容忍误差。真正的工程系统（接触冲击、结构振动、高压浪涌）的 s 远大于 9 对应的逼近阶数。

### 9.2 层数与逼近精度

用 N 层能逼近的系统，其逼近误差随 N 的衰减速率取决于被逼近函数的光滑性（Bernstein 定理）：

```
E_N = O(N^{-α}),    α = s / d

其中 s —— 系统的光滑性阶数（越高越光滑）
      d —— 问题维度（本项目 d = 3 空间 × 1 时间）
      α —— 收敛速率指数
```

对本系统：接触问题 s ≈ 1（一阶导数不连续），d = 4 → α = 0.25。**每把层数翻倍，精度只提高 2^{0.25} ≈ 1.19 倍**——收益递减极快。

这是为什么前一份文档坚称"十层不是过度设计，而是必要但远不够"的数学根源。

### 9.3 推荐的本系统"自然分层"——基于特征模态

不是按"功能"切，而是按**数学上时间-频率的特征模态**切：

```

频率范围           对应主导方程           本项目的工程称谓
─────────────────────────────────────────────────────────────────
DC ~ 1 Hz         任务规划 / NLP 理解         L6 VLA
1 Hz ~ 20 Hz      RL Actor 策略更新          L4 RL
20 Hz ~ 50 Hz     多体柔顺运动               L5 规划
50 Hz ~ 200 Hz    模态振动（结构共振）       StructuralFEM 截断
200 Hz ~ 1 kHz    阻抗控制 + 力控            L3 阻抗
1 kHz ~ 10 kHz    电流环                     L2 FOC
10 kHz ~ 100 kHz   EMI + 开关谐波             State space average 未覆盖
100 kHz ~ 1 MHz    电缆反射 + 反射           Telegrapher 方程
1 MHz ~ 100 MHz    芯片内部数字信号           EDA 工具链覆盖
> 100 MHz         原子/量子效应               器件物理未建模（包含在模型参数中）

```

这个切法的好处：**数学上正交**——每一模态的特征值区间内，方程可以独立近似求解；层间只有弱耦合（通过边界条件连接）。这个正交性是**唯一在数学上有保证**的分层方法。当前项目用的"功能性分层"（按职能分：感知/决策/执行）不是数学意义上的近似正交——同一个数学方程的两半可能被切成两层（如 FOC 三相模型的一部分在 L2，PWM 开关纹波在 S，电流环在 L2，EMI 在未覆盖区间）。

## 十、本项目的数学覆盖度

对照上面 §九.三 的频率-数学分解，标注当前项目各模块究竟覆盖到哪个数学层级：

| 频段 | 数学结构 | 本项目实现 | 覆盖度 |
|-----|---------|----------|-------|
| DC ~ 1 Hz | 语言模型 | vla_model.py + nanoGPT | 🟢 ~50M 参数可训 |
| 1 ~ 20 Hz | 随机微分方程 | rl_algorithms.py + SAC | 🟡 算法级, HIL 待验证 |
| 20 ~ 50 Hz | ODE 多体 | mcts + climb_dynamics | 🟡 单机, 真机待验证 |
| 50 ~ 200 Hz | PDE 模态截断 | KinematicsDynamics (解析) | 🟡 仅运动学 |
| 200 ~ 1 kHz | 传递函数 + DAE | multi_rate_ekf + foc | 🟡 双轨未闭环 |
| 1 ~ 10 kHz | 状态空间平均 | foc_board_align | 🟢 双轨对齐完成（v1.1） |
| 10 kHz ~ 100 kHz | 开关谐波 + 共模 | EMCAnalyzer (量级) | 🔴 仅量级判断 |

**结论**：当前项目的数学覆盖集中在 DC ~ 10 kHz 区间——约覆盖系统全频段能量的 60~70%。剩余 30~40% 是"未建模但客观存在"的规律——这就是为什么项目坚持要求 HIL 校准 + 真机验证的数学原因：**仿真器的数学方程在那 30~40% 区间没有解析解，只能用实测补充。**

## 十一、总结——数学视角下的"系统是什么"

| 层次 | 主宰的数学 | 工程体现 |
|-----|----------|---------|
| 内部物理 | PDE + 量子 | 芯片/器件特性，输入为参数 |
| 连续动力学 | DAE + Index theory | 关节/电路/接触，决定瞬时响应 |
| 离散切换 | 混合自动机 + LCP | 接触/安全/档位，决定拓扑跳变 |
| 滤波/估计 | 概率论 + Kalman | 将噪声观测转化为状态信念 |
| 反馈控制 | Lyapunov + LQR/MPC + 鲁棒 | 将信念转化为稳定动作 |
| 策略优化 | 信息论 + RL + 模仿 | 将任务目标转化为控制律参数 |
| 形式验证 | 可达集 + STL | 安全边界的严格数学保证 |
| 仿真/验证 | FEM + 数值积分 | 把数学预言变为实验可验证量 |

每一层数学结构不同——有的是 ODE 的解的存在性，有的是博弈的不动点，有的是 KL 散度的收敛速率，有的是 DAE 指标的良态性。但整个系统在同一时间、同一空间里必须同时满足所有这些数学约束——这本身就是一个极值问题，其解的存在性和唯一性没有任何定理先验保证。

**这就是具身智能机器人真正的难度——不是"模块堆砌"，是在不同空间/不同时间尺度的多个数学结构间找一个全局相容的解。项目每次突破都是一次"约束相容性"的成功——没有数学上的捷径，只有逐步缩小解空间直到可行域非空。**
