## 三、分阶段探索计划

### Phase A (Month 1-3): 仿真闭环打通

**目标**: 让仿真中的 RL 策略成功迁移到真实硬件（哪怕是简化版）

```
Month 1: 仿真环境搭建
  ├── 选择仿真平台 (Isaac Sim / MuJoCo / PyBullet)
  ├── 搭建简化家庭场景 (桌面、杯子、毛巾)
  ├── 实现 URDF 导入 + Pinocchio 运动学/动力学
  └── 集成 TACTO 视触觉仿真

Month 2: RL 训练管线
  ├── 行为克隆: 20h 遥操作数据 → 策略初始化
  ├── RL 微调: PPO/SAC + 域随机化
  ├── 基础技能: "抓取刚性物体" 达到 80% 成功率
  └── 触觉集成: 滑脱检测 + 力控制

Month 3: Sim-to-Real 迁移
  ├── 域随机化调参
  ├── LoRA 微调 (少量真实数据)
  ├── 真机测试 + 数据分析
  └── 建立 "仿真→真机差距" 的量化评估
```

**关键里程碑**:
- [ ] 仿真环境可运行（实时渲染 + 物理）
- [ ] 行为克隆策略在仿真中 >80% 成功率
- [ ] 至少一个技能通过 Sim-to-Real 迁移
- [ ] 量化 Sim-to-Real 差距报告

### Phase B (Month 3-6): 核心数学扩展

**目标**: 补齐柔性体动力学 + 全身运动控制数学

```
Month 3-4: 柔性体动力学
  ├── 选择建模方案 (FEM vs 质点弹簧 vs 学习近似)
  ├── 实现毛巾/塑料袋的形变仿真
  ├── 柔性接触: Hunt-Crossley + 分布式接触力
  └── 验证: 仿真形变 vs 真实形变对比

Month 4-5: 全身运动控制
  ├── 双足行走: ZMP + 线性倒立摆
  ├── 添加上半身: 浮动基座 + 多接触力平衡
  ├── 全身协调: 接触约束 + 任务优先级
  └── 验证: 2D → 3D 行走仿真

Month 5-6: VLA 小模型训练
  ├── 数据收集: VLA 格式 (图像+指令→动作)
  ├── 模型: 100M 参数级别 VLA
  ├── 训练: pretraining + SFT + RLHF
  └── 评估: 家庭服务任务零样本泛化
```

**关键里程碑**:
- [ ] 柔性体仿真可运行 (毛巾折叠、塑料袋抓取)
- [ ] 双足行走仿真稳定 (抗扰动)
- [ ] VLA 小模型完成预训练
- [ ] VLA 在简单家庭任务上的零样本成功率 >30%

### Phase C (Month 6-12): 系统化与论文产出

**目标**: 产出可发表的研究成果 + 系统化工具链

```
Month 6-8: 论文准备
  ├── 选题: "从攀岩到家庭服务" 或 "触觉-视觉概率融合"
  ├── 实验: 完整实验 + 消融研究
  ├── 撰写 → 投稿 ICRA / IROS / CoRL
  └── 开源代码 + 数据集

Month 8-10: 安全认证框架
  ├── 功能安全 ISO 13482 (个人机器人)
  ├── 硬件安全: 故障模式 + 冗余设计
  ├── 软件安全: 运行时监控 + 紧急停止
  └── 文档化安全论证

Month 10-12: 灵巧手原型
  ├── 设计决策: 3指/5指, 欠驱动/全驱动
  ├── CAD 建模 + 材料选择
  ├── 原型制造 (3D 打印/CNC)
  └── 集成测试: 抓取 50+ 家庭物体
```

**关键里程碑**:
- [ ] 1-2 篇 ICRA/IROS 投稿
- [ ] 安全认证框架文档完成
- [ ] 灵巧手原型可演示
- [ ] 项目 GitHub 达到 100+ star (开源后)

### Phase D (Month 12-18): 长期探索

**目标**: 终身学习 + 多机器人协作

```
Month 12-14: 终身学习框架
  ├── 问题定义: 如何在不断学习新任务时不遗忘旧技能
  ├── 技术路线: EWC / PackNet / Progressive Neural Networks
  ├── 验证: 序列学习 10+ 家庭任务
  └── 评估: 旧任务保留率 >90%

Month 14-16: 探索性项目 (选做)
  ├── 选项 A: 多机器人协作 (2机器人协作家务)
  ├── 选项 B: LLM+RL 融合 (大模型指导 RL 策略搜索)
  ├── 选项 C: 脑机接口控制 (disabled用户辅助)
  └── 选项 D: 野外环境适应 (非结构化场景)

Month 16-18: 综合演示
  ├── 准备 30 分钟完整演示
  ├── 涵盖所有核心技术
  └── 视频录制 + 宣传材料
```

## 五、风险分析与缓解策略

### 5.1 技术风险

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| 仿真到真机差距过大 | 60% | 致命 | 早期 Sim-to-Real 验证、域随机化、LoRA微调 |
| 触觉传感器硬件故障率高 | 40% | 高 | 多传感器冗余、快速更换设计 |
| 算力限制导致无法实时 | 30% | 高 | TensorRT INT8、模型蒸馏、边缘计算 |
| 家庭场景过于多样化 | 70% | 中 | 任务抽象 + 技能分解 + 元学习 |

### 5.2 工程风险

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| 电机驱动 DIY 失败 | 30% | 中 | 购买成熟驱动 + 仅定制关机电路 |
| 机械结构强度不足 | 40% | 中 | 3D 打印 + 金属关键件 |
| 嵌入式 Linux 启动困难 | 50% | 高 | 使用 Jetson 官方 BSP + 模块化解耦 |
