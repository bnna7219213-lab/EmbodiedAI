## 二、两份《接触动力学优化》文档精读结论

### 2.1 已有资产（值得保留，本报告全部继承并扩展）

| 改进点 | 内容 | 评价 |
|---|---|---|
| 软接触模型 | Hunt-Crossley: f = k·δ^1.5·(1 + b·δ̇)，可微、免互补约束 | ✅ 正确且关键，但 **k、b 无推导来源**（补：Hertz 推导见配套文档 §2.1-2.2） |
| Stribeck 摩擦 | μ(v) = μ_c + (μ_s−μ_c)·exp(−‖v‖/v_s) | ✅ 合理，参数需标定 |
| 二阶锥摩擦锥 | ‖f_t‖₂ ≤ μ·f_n ⟺ SOC 约束（替代金字塔线性化） | ✅ 正确；线性化误差分析（内切 1−2/π≈−36% 面积）严谨 |
| Ferrari-Canny | 力闭合质量指标 | ⚠️ 代码实现与标准定义不符（采 6D 球面 + ‖α‖≤1 的投影并非标准 Q₁ 指标），且 100-200 次 LP 求解不可实时 |
| 分层框架 | Level 1 离散模式搜索(A*) / Level 2 QP / Level 3 1kHz 反馈 | ✅ 架构正确，但 Level 2 的"动力学约束"是伪代码（`...` 省略号），不可运行 |
| MPC 集成 | 滚动优化 + warm start | ⚠️ 框架性描述 |

### 2.2 两份文档自身的三个结构性局限

1. **准静态假设贯穿始终**：Level 2 的力平衡是 `∑f_i + f_gravity = m·a`（a≈0），**没有惯性项、没有角动量、没有浮基方程**。这决定了它只能解决"抓握物体"而不能解决"攀岩者自身作为浮基系统的运动"——攀岩时机器人本体是那个被重力作用的自由浮动刚体，四 limb 的接触力必须同时满足 6 维 wrench 平衡 **加** 角动量方程。
2. **无冲击/脉冲动力学**：竞技攀岩的 dyno（动态跳跃抓点）在捕获瞬间是脉冲过程 M(ν⁺−ν⁻)=JᶜᵀΛ，需要脉冲摩擦锥 ‖Λ_t‖≤μΛₙ 与牛顿回复系数，两份文档完全没有。
3. **与融合层无接口**：优化出的力 λ 与触觉传感器的测量模型（噪声、标定矩阵、帧率）之间没有任何概率连接——力是确定的，传感器是理想的。

### 2.3 与迁移文档的资产对照（跨文档综合）

《攀岩接触规划迁移到家庭场景》已引入 Hertz（E*、δ=(F/(E*√r))^(2/3)）、滚动接触、线性 FEM——但这些全部服务于**家庭物体**。两份《接触动力学优化》文档的 Hunt-Crossley 刚度 k 与迁移文档的 Hertz 推导**至今没有打通**（同一个物理量，两处独立出现、数值来源不明）。配套文档 §2 将完成这个统一推导。

## 四、关键证据摘录（支撑以上判断）

1. plan.md 全 1202 行：无浮基动力学、无质心动力学、无接触雅可比、无角动量方程、无摩擦锥约束（已逐项核查）。
2. 触觉融合文档 L306-314 的混合整数最优控制问题中，动力学约束 x_{t+1}=f_dynamics(x_t,u_t,f_t) 中 f_dynamics 未定义；L722 CITO 的 M(q)v̇+h=Sτ+Jᵀf 是待接入 Pinocchio 的注释。
3. gap-analysis-realtime-tactile.md：标题为"触觉融合网络实时性"，但 TactileEncoder/VisualEncoder/CrossModalAttn 全部按黑盒处理，"融合的数学内容为零，只有接口 shape (B,5,3,48,48)"。
4. MultiModalFusionPolicy 在 Jet.md：优化版融合明确退化为 `concat + 两层 MLP` 并删除注意力；唯一有数学定义的是效率目的的线性注意力（与融合语义无关）。
5. 静平衡检查（触觉融合文档）：`required_friction = weight×0.3` 为经验常数；法向力≈weight×size×2.0 无推导。
6. RL 文档：P(s'|s,a) 转移核中摩擦/碰撞仅为文字列举；摩擦系数只是域随机化表里一个 uniform 采样参数——动力学被压缩成"仿真器黑箱 + 随机化一个 μ"。
7. nn-to-hardware-pipeline.md：从 AI token 直接跳到电流/力矩，机械动力学被压缩为"机械时间常数 5-20ms"一阶滞后。
8. 攀岩场景现状：三份 gap 分析将攀岩定位为"方法论源头 + 数据对照组"，竞技维度（速度、dyno、动态时刻）**零数学覆盖**；ClimbingMCTS 保留的仅是准静态骨架。

## 六、结论

1. 项目"从攀岩转向家庭服务"的决策在数据/架构层论证充分，但**物理数学层从未真正建立**——攀岩原生的准静态数学（摩擦锥、支撑多边形、MCTS）与两份《接触动力学优化》的抓取力优化，都不包含"机器人自身作为浮基刚体在重力场中通过接触力运动"这一层。
2. 触觉-视觉融合目前是全项目数学上最薄弱的一环：工程链路（TensorRT/INT8/延迟预算）扎实，融合语义零数学。补上概率基础后，现有神经网络融合可被解释为 EKF 的非线性推广，而非替代品。
3. 竞技攀岩所需的动态能力（摆荡、dyno、冲击捕获、速度-风险权衡）有清晰、可实现、可验证的数学结构——配套文档给出了完整公式与可运行代码，且所有数值结论（软指尖载荷极限、柔顺捕获的必要性、μ 不确定性对握力的定量影响）均可由 `climbing_dynamics_core.py` 复现。
