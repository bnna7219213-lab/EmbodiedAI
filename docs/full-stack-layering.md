# 全栈机器人层级总图（底层硬件 → 顶层 AI）

> **版本**: v2.0 | **日期**: 2026-10-08
> **覆盖范围**: 101 个 Kotlin 引擎 + ~200 个 Python 模块 + 4 份跨项目契约
> **阅读方式**: 从下往上看，每一层依赖其下方所有层

---

## 分层法说明

本项目有**三套编号系**必须保持不冲突：
- **控制栈（L0–L6）** — AI 运行时控制链路（指令从顶到底）
- **物理栈（P0–P8）** — 实体硬件制造层级（芯片到整机）
- **数据栈（D0–D5）** — 数据反馈通道（飞轮回流）
- **横切栈（S）** — 安全与物理引擎（横跨全栈）

控制栈方向 ↓ （指令下传）
数据栈方向 ↑ （真机数据上灌）

## 一句话总结

> **P0 三引擎 + P1 四引擎（Safety/Sim/HIL）= 底层物理计算骨干**

> **横切栈 S（确定性+概率性+形式性）= 所有动作必须经过的安全闸门**
> **物理栈 P0–P8 与数据栈 D0–D4 正交——任何一个 L 层的安全/性能都有对应的物理层和数据层支撑。**
